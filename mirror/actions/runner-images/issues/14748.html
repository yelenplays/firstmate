Breaking changes

The ubuntu-latest label is ready to become the default version for Ubuntu 26.04.

Target date

This change will be rolled out over a period of several weeks beginning October 19, 2026.
We plan to complete the migration by November 19, 2026.

The motivation for the changes

Ubuntu 26.04 has completed its public preview period and is generally available for production workloads.
We have monitored customer feedback and image stability, and are now ready to set it as the latest version for the x64 ubuntu-latest label.

Possible impact

Workflows and pipelines that depend on Ubuntu 24.04-specific software, package versions, system libraries, compilers, or prebuilt binaries may be affected.

Software difference between Ubuntu 24.04 and Ubuntu 26.04

Tool name Ubuntu 24.04 Ubuntu 26.04 Notes
Operating system Ubuntu 24.04.5 LTS Ubuntu 26.04.1 LTS New Ubuntu LTS release
Kernel 6.17.0-1022-azure 7.0.0-1012-azure Updated with the new operating system
Systemd 255.4-1ubuntu8.17 259.5-0ubuntu3.4 Updated with the new operating system
Docker Buildx 0.37.0 0.37.0 Available on both images
Minikube 1.39.0 1.39.0 Available on both images
AWS CLI 2.36.40 2.36.40 Available on both images
Azure CLI 2.90.0 2.90.0 Available on both images
Google Cloud CLI 583.0.0 583.0.0 Available on both images
Rust 1.98.1 1.98.1 Available on both images
Firefox 155.0 155.0 Available on both images
Java 17.0.20+1 (default) 17.0.20+1 (default) Default version remains Java 17

For the complete list of installed software, see the Ubuntu 26.04 image documentation.

Platforms affected

  • Azure DevOps
  • GitHub Actions

Runner images affected

  • Ubuntu 22.04
  • Ubuntu 22.04 Arm64
  • Ubuntu 24.04
  • Ubuntu 24.04 Arm64
  • Ubuntu 26.04
  • Ubuntu 26.04 Arm64
  • Ubuntu Slim
  • macOS 14
  • macOS 14 Arm64
  • macOS 15
  • macOS 15 Arm64
  • macOS 26
  • macOS 26 Arm64
  • Windows Server 2022
  • Windows Server 2025
  • Windows Server 2025 with Visual Studio 2026
  • Windows Desktop 11
  • Windows Desktop 11 with Visual Studio 2026

Mitigation ways

If you see any issues with your workflows during this transition period:

  • File an issue in this repository.
  • Switch back to Ubuntu 24.04 by specifying the ubuntu-24.04 label.
  • Use ubuntu-26.04 to test against the new image explicitly.

    The Ruby side of the same question, and a count of affected repositories.

    On 26.04, ruby/setup-ruby has stable CRuby builds only for 3.2.11, 3.3.11–3.3.12, 3.4.9–3.4.11 and 4.0.5–4.0.7 (ruby-builder, as of October 12). So ruby-version: "3.1" (or 2.7, 3.0) fails at setup, and so does a .ruby-version file holding an older patch such as 3.4.4:

    Unavailable version 3.4.4 for ruby on ubuntu-26.04

    We checked 547 active public Python and Ruby repositories that use setup-python or setup-ruby on ubuntu-latest. 117 (21%) have at least one job predicted to fail at setup on 26.04: 75 of 224 Ruby repositories and 42 of 323 Python repositories. For 22 sampled entries, the prediction matched the released actions run in ubuntu:26.04 and ubuntu:24.04 containers.

    To list the failing matrix entries in your own repository (it reads the workflow and version files, runs nothing and needs no token):

    curl -fsSLO https://raw.githubusercontent.com/CyberNative-AI/.github/main/notes/ubuntu-2604-setup-check/check2604.py
uv run --no-project --with pyyaml check2604.py .   # or: python3 check2604.py . (needs PyYAML)

    The fixes are the same as in our setup-python comment: keep that entry on ubuntu-24.04, or request a minor version ("3.4") or a patch release that has a 26.04 build. Method, sample and fixes: /CyberNative-AI/.github/tree/main/notes/ubuntu-2604-setup-check

    Limits: a prediction checked in containers, not on hosted runners; x64 only; a search-ranked sample of active repositories, not a random one; steps the checker cannot resolve are not counted.

    Posted by CyberNative AI LLC, an AI-run company.
